# Конфигуратор Zeekr X

Только конфигуратор: без шапки, логотипа, подвала и цен. Его собирают в сборку и встраивают в страницу модели на сайте.

Посмотреть: https://tema-mail.github.io/zeekr-x-konfigurator/ (закрыт от индексации).
Локально: `python3 -m http.server 8940`, затем http://127.0.0.1:8940/

## Что выбирает человек
Версия (Max, 5 мест, Max, 4 места, Ultra, 5 мест); цвет кузова, диски, цвет салона, экран пассажира, отделка салона; дополнительно – автоматические безрамочные двери, панорамная крыша с затемнением, холодильник в консоли.
Варианты и правила совместимости – из официального конфигуратора Zeekr (zeekrlife.com), выбор подстраивается сам.
Диски, которые Zeekr сейчас по акции меняет на другие, есть с пометкой.

## Картинки
Официальные рендеры Zeekr конкретной сборки: главный кадр без фона, ракурсы спереди ¾, сбоку, сзади ¾ (где Zeekr их сделал)
и салон (если Zeekr даёт картинку салона для этой модели). 72 сборок кузова, 0 вариантов салона, всё в WebP.

## Встраивание в сайт
Скопировать блок `<div class="z9" data-z9>…</div>` из `index.html`, подключить `css/konfigurator.css`,
`js/zeekr-data.js`, `js/konfigurator.js`, положить рядом папку `img/`. Движок общий для всех моделей Zeekr,
модель задаёт только `js/zeekr-data.js` и картинки. Цвета – токены `--z9-*` в начале CSS (светлая и тёмная тема).

Заявка «Отправить сборку менеджеру»: у формы атрибут `data-endpoint` – адрес приёма заявок сайта,
туда уходит POST JSON `{name, phone, text, url, lines, source, page}`. Пока он пустой, заявка уходит событием:
```js
document.querySelector('[data-z9]').addEventListener('zeekr:lead', e => send(e.detail));
// текущая сборка в любой момент: window.ZeekrCfg.get()  → {text, lines, config, url}
// каждое изменение: событие 'zeekr:change'
```
Ссылку на политику конфиденциальности вписать в `a[data-policy]` формы. Сборка хранится в адресе (`#v=55&o=…`).

## Как обновить данные
Инструменты в `tools/` (нужны Python 3, Playwright, Pillow; запросы идут с российского или китайского адреса –
zeekrlife.com не отвечает адресам из Европы):
1. `sniat-opcii.py 3 <код года из списка моделей>` – открывает страницу заказа 9X и снимает версии и опции через их API → `z9x-raw.json`;
2. `svod.py z9x-raw.json model.json` – правила совместимости и список нужных кадров → `model.json`;
3. `skachat.py model.json 3 raw` – скачивает кадры в `raw/` (6 потоков, повторы, ракурсы ищутся по всем версиям);
4. `kadry.py raw img/zeekr-x` – WebP; `ikonki-dekora.py model.json img/zeekr-x` – иконки декора из рендеров;
5. `dannye.py model.json js/zeekr-data.js "Zeekr X" X img/zeekr-x 3` – данные для страницы (переводы названий в нём).

Данные сняты 12.11.2026, модель Zeekr X (modelInfoId 3). Сборка и выкладка новой модели целиком – `tools/novaya-model.sh`.
